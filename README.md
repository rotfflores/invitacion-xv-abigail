# Invitación XV años · Abigail

Invitación web responsiva inspirada en una estética floral, romántica y editorial. Incluye galería original, detalles del evento, código de vestimenta, confirmación por WhatsApp y cuenta regresiva.

## Vista local

Abre `index.html` directamente o inicia un servidor estático:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000`.
